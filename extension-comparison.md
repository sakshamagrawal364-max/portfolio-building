The Python and Java extensions helped me run programs directly in VS Code and provided syntax highlighting and code suggestions. Prettier made my HTML easier to read by organising indentation and spacing, while GitLens showed the author, time, and commit details for a line of code. I found Prettier most useful for everyday editing because it reduced manual formatting work. I would keep Prettier and GitLens enabled regularly and use the Python and Java extensions for their respective languages.
